# atoll's Cast receiver

The page a Chromecast, a Google TV or a Nest speaker loads when the atoll podcast app casts to it. It's a [Google Cast Web Receiver](https://developers.google.com/cast/docs/web_receiver): Google's receiver framework plays the episode and takes the app's controls, and this page shows the episode's cover art, title and show.

GitHub Pages serves it at <https://johnconrad.github.io/atoll-cast-receiver/>, the address registered for atoll's receiver in the Google Cast developer console. Only this page lives here; the app is elsewhere.
